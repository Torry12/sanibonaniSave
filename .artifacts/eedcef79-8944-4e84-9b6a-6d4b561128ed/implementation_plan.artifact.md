# Implementation Plan: Live Financial Flows Simulation

This plan outlines the creation and execution of a live simulation test covering payment escalation, loan disbursements, and repayments in the SanibonaniSave platform.

## Proposed Changes

### [Component Name] Financial Simulation Runner

#### [NEW] [FinancialFlowSimulationRunner.kt](file:///C:/Users/CRISS/AndroidStudioProjects/SanibonaniSave_Full/app/src/test/java/com/sanibonani/save/FinancialFlowSimulationRunner.kt)
- Create a JVM test that connects to the live Supabase backend.
- **Step 1: Setup**
    - Sign in as Platform Admin (`torrymsimango@gmail.com`).
    - Create a transient group (`SIM-FLOWS-XXXX`).
    - Register 5 simulated members.
    - Inject initial liquidity (R10,000) via `increment_group_balance`.
- **Step 2: Payment Escalation Flow**
    - Create a payout request of R2,000.
    - Transition status: `PENDING` -> `GROUP_APPROVED` (Escalated to Platform).
    - Transition status: `GROUP_APPROVED` -> `COMPLETED` (Approved by Platform Admin).
    - Verify group balance reduction and ledger entry.
- **Step 3: Loan Disbursement Flow**
    - Create a loan application for a member (R1,000).
    - Transition status: `PENDING` -> `ACTIVE` (Approved and Disbursed).
    - Use `approve_and_disburse_loan_v1` RPC.
    - Verify group balance reduction and loan status.
- **Step 4: Repayment Flow**
    - Record a loan repayment of R500.
    - Use `record_loan_repayment_v1` RPC.
    - Verify member's `total_repaid` in the loan and group balance increase.
- **Step 5: Integrity Check**
    - Run `audit_and_fix_group_balance_v1` to ensure no balance drift occurred during simulation.
