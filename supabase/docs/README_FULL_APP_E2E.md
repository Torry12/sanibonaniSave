# Full-app E2E data

There is no separate `25_SEED_FULL_APP_E2E.sql` / `26_VERIFY_FULL_APP_E2E.sql` pack in this repository. Full-app coverage now comes from the integrated local seed.

## Source of truth

`supabase/SEED_ALL_DATA.sql` is generated by `supabase/scripts/generate_integrated_seed.ps1` from these modules, in this order (`00_REBUILD_ALL.sql`):

1. `MASTER_SEED_DATA.sql` — QA actors, core group types, members, loans, beneficiaries, polls, opening ledger.
2. `11_SEED_TEST_DATA_10_GROUPS_100_MEMBERS.sql` — 10 groups / 100 members with 12 months of history and banking data.
3. `16_SEED_50_PAYMENT_REQUESTS_AND_APPROVALS.sql` — mixed-status payout requests.
4. `17_SEED_PLATFORM_FINANCIAL_ESCALATIONS.sql` — platform escalations, pending loans, claims.
5. `19_SEED_BURIAL_CLAIM_ESCALATIONS.sql` — burial claim escalations.
6. `31_REAL_LIFE_INTEGRITY_SEEDS.sql` — deliberate audit/fraud fixtures (`LIGHT-Stokvel` only).
7. `20_SEED_12_MONTHS_TRANSACTIONS.sql` — 12-month transaction and ledger history.
8. `21_SEED_VALID_BURIAL_CLAIMS.sql` — valid burial claims.

## Coverage

- All group types: burial society, stokvel, ROSCA, investment club, emergency fund, community savings, tontine, other.
- Member lifecycle states, contribution/payment pipelines, loan lifecycle, payouts, claims, and platform fees.
- Ledger history for support, reconciliation, and simulation flows.

## Run

```powershell
npx supabase db reset      # local only; applies SEED_ALL_DATA.sql
```

Never apply this seed to the cloud tier; cloud changes use a dated `online/SYNC_DELTA_<date>.sql`.

## Verify

Use the read-only queries in `docs/SEED_DATA_INSTRUCTIONS.md` section 3 (group/member counts, escalation tabs, ledger-vs-cache balance check), or run `supabase/scripts/TOTAL_INTEGRITY_AUDIT.sql` against the local database.

## Notes

- All seed identities are scoped with `SEED-` / `LIGHT-` / `SIM-FLOWS-` prefixes so cleanup is safe.
- `31_REAL_LIFE_INTEGRITY_SEEDS.sql` intentionally creates ledger/cache drift for audit testing; do not "fix" those fixtures.
